# Component source candidates

Use when the current interface lacks a needed pattern and external references or source would help. Inspect the existing components first; a supplied or installed library takes precedence when it fits. Select by task, framework, token compatibility and maintained behavior, rather than by a gallery's visual polish.

_Capabilities and published access terms checked against the linked sites on 2026-10-13. These are discovery candidates; no component integration, accessibility or performance certification is implied. Check the selected source and current licence before adoption._

| Source | Use when | Stack and access notes |
| --- | --- | --- |
| [AffectUI](https://www.affectui.com/) | AI chat, agent runs, evaluations or complete AI-product screens need a reference or editable source | React components with their own styles; free and Pro items. The site also offers MCP and agent-readable docs. |
| [Kobra](https://kobra.systems/) | Agent/chat states, streaming text, citations, forms or tables need a concrete React pattern | Inspect the selected component's dependencies. Licence coverage was not established in this review; use as a reference until it is confirmed. |
| [Arc UI](https://uiarc.dev/) | A shadcn/Next.js surface needs animated components or blocks | Free source is MIT; Pro has separate terms. Its [licence page](https://uiarc.dev/license) was labeled draft when checked. |
| [Evil Charts](https://evilcharts.com/docs) | A React dashboard needs styled chart compositions | Recharts and Apache ECharts variants; [public repository](https://github.com/legions-developer/evilcharts) is MIT. Select the engine from the chart's needs. |
| [Transitions.dev](https://transitions.dev/) | An interaction needs a transition recipe or motion reference | Includes a library, builder and agent/skill tooling. Inspect any proposed CLI, skill or CI integration separately; a recipe lookup needs none of them. |
| [beUI](https://beui.dev/) | A React surface needs animated controls, overlays, charts or AI-interface patterns | React 19, Tailwind 4 and Motion; public source is MIT, Pro is separately licensed. Components can add dependencies. |
| [BoardUI](https://www.boardui.com/) | A dashboard needs tables, chart cards, shells or templates | React/Tailwind; [free source is MIT and Pro has seat/use terms](https://www.boardui.com/license). Adapt its tokens to the consuming system. |


Before copying or installing code, inspect the selected source/dependencies and confirm licence coverage for its intended use. Check meaningful keyboard/focus, touch, responsive and reduced-motion states. Preserve required notices, adapt tokens and APIs, and record adoption in the project's existing design contract. A website preview does not prove that the component works in the consuming app.

## Complementary tools

- [tweakcn](https://tweakcn.com/) explores shadcn/Tailwind theme choices. Reconcile exported values with the existing semantic tokens. [Source](https://github.com/jnsahaj/tweakcn).
- [React Aria](https://react-aria.adobe.com/) supplies style-free React interaction primitives with accessibility and internationalization behavior. Use when the existing primitive layer has a supported gap.
- [Storybook](https://storybook.js.org/) provides isolated component states, documentation and interaction/accessibility checks. Reuse it when present; a small repair can use an existing preview harness.

These capabilities were checked against primary sites on 2026-10-13. This reference installs nothing and does not require a particular framework for unrelated work.
