# Decision map

| ID | Question and consequence | Evidence/options | Depends on | State/owner | Next check |
| --- | --- | --- | --- | --- | --- |
| D1 | A choice that changes the project | Known facts and credible options | Required earlier decisions | Open, investigating, decided, or superseded | The smallest useful investigation |

Keep accepted decisions linked to their authoritative records. Record assumptions separately. When superseding a choice, explain which evidence changed and which dependent work must be reconsidered.

Use a graph when dependencies are hard to scan. Leave unknown areas broad; do not invent precision or require one session per decision. Ready implementation work belongs in a phase/task plan, linked back to the decisions it depends on.
