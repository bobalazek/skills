# Create carousel

Produce the requested social image sequence, swipe document or its outline. Reuse accepted copy, evidence, voice, assets and templates. A small revision stays small; an outline request finishes with the outline. Interactive website carousels belong to `design-interface`; talk and meeting decks belong to `create-presentation` when available.

## Set the output

Read project instructions and supplied material. Establish the audience, supported message, destination and requested fidelity. Distinguish an ordered image set from a multipage document; the word "carousel" alone does not specify a file format. Ask only about missing choices that materially affect the result, such as a required editable format or an ambiguous destination. Preserve accepted slide counts and copy constraints; propose missing choices with their assumptions.

Inspect the existing renderer or authoring tool before promising an output. For production, use [the tool paths](references/production-tools.playbook.md) to choose native design editing, browser rendering or an existing image pipeline. Preserve the requested editable format; do not silently substitute flattened exports or another authoring format. This package bundles neither a renderer nor a paid media service. Record unavailable assets, tools or inspection access and continue independent writing/layout work where useful. Generation spending, uploads and publication need applicable authority; honor authority already granted.

For a destination-ready export, verify the exact surface and current requirements in its official documentation: accepted artifact kind, item/page count, dimensions/aspect, file type/size, accessibility fields and relevant cropping. Record the source and check date. A general design draft can use stated assumptions; unverified destination requirements leave compatibility unchecked. Do not embed platform limits in a reusable template.

## Compose the sequence

For a new set or several variants, use [the carousel plan](references/carousel-plan.template.md) to keep slide order, evidence and outputs together in the consuming project's existing records. When writing or reworking the cover, panel sequence or layout system, read [carousel craft](references/carousel-craft.playbook.md). Start with the reader's reason to continue, develop the supported message, and end at the requested conclusion or next action. Each slide needs enough context to make sense when encountered separately. Preserve useful copy; do not force every sequence into the same slide count or sales structure.

Trace numbers, quotations and product claims to sources. Keep placeholders visibly marked and out of a claimed final export. Product screenshots can come from `capture-product-screens` when available, as seeded, reproducible captures with a shot manifest. Check permission and attribution for supplied images, fonts and logos; a reference is not permission to reuse it. Inspect references for useful composition or hierarchy without copying distinctive content. This skill owns the set's wording and optional accompanying caption. Use an existing voice guide; `review-writing` can assess prose when available, or directly check clarity, supported meaning and retained voice.

Reuse the accepted layout family. Put important text, charts and brand marks in editable layers with their real content. Fit content by editing or relaying out; do not silently crop, ellipsize or shrink key text until it becomes unreadable. Use a consistent canvas within each image set and matching page proportions for a document. A second aspect ratio needs its own layout check. Preview the cover and a dense or visually risky slide before batch export when the look is unsettled; accepted templates and minor fixes need no new aesthetic approval.

## Export accessible artifacts

Keep an editable source and assemble files in explicit slide order. Include per-slide text alternatives that convey essential wording and visual information, plus an ordered text transcript for a sequence whose meaning depends on several slides. Complex charts may need a longer description or data table; follow [W3C's complex-image guidance](https://www.w3.org/WAI/tutorials/images/complex/) when needed. Edit descriptions to fit destination fields without discarding essential meaning. When a destination lacks those fields, provide an accessible text companion and state how it accompanies the set.

For PDFs, preserve real text and document structure where the tool supports them. Check image alternatives and logical reading order using [W3C's PDF image-alternative](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF1) and [reading-order techniques](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF3). An image-only PDF or selectable text alone does not establish accessibility. Record export limitations and provide the text companion; do not claim PDF accessibility that was not checked.

Open the actual exported images or render every PDF page. Check slide/page count and order, canvas dimensions, file type/size and applicable destination limits. Inspect every slide at its intended viewing size, including mobile/feed size where relevant; examine the cover at thumbnail size. Check text fit, contrast, meaningful charts, asset sharpness and cropping. Compare rendered wording and figures with the accepted source. Text extraction or OCR can help find omissions but cannot replace visual inspection or reading-order checks.

Repair defects and recheck affected exports and assembled order. A successful render command, a contact sheet alone or an uninspected PDF is insufficient proof. Tie observations to the actual artifact revision and name inaccessible checks.

## Review and hand off

Before acceptance, have a separate agent in fresh context challenge the raw request, source facts, ordered content, editable source and actual exports/evidence without the author's conversation or preferred answer. Retain the returned reviewer/session identity, assessed revision, findings and coverage. Fix demonstrated defects and obtain an independent recheck of affected results. If that assessment is unavailable, label the result unreviewed; it supplies neither missing inspection evidence nor human approval.

Return the requested source, ordered exports and text alternatives/transcript, with observed checks, rights/attribution notes and exact gaps. Include the reproduction command/tool version when production used code. An outline or layout draft remains that deliverable; do not present it as a rendered or published set.

Stop at the requested delivery. A presentation adaptation can pass the accepted sequence to `create-presentation`; animation can pass it to `create-motion-video`. Use those skills only when available and the additional result is requested, otherwise describe the plain action and its prerequisite. Continue already-authorized work without an extra permission loop.
