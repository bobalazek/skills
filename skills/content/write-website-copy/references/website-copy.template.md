# Website copy handoff

Use for several sections or requested search metadata. Keep these fields in the existing content source or handoff; omit irrelevant fields. A single headline rewrite can return its wording and any necessary fact check directly.

## Context

Record the page/section and source revision, audience and intended decision, entry promise, confirmed offer, action/destination, voice examples and actual language or space constraints. Link an accepted page plan when one exists. State whether the result is proposed, accepted or integrated; none of those labels establishes measured performance.

## Copy and supporting facts

| Location or existing content key | Recommended wording | Support and constraints | Gap or checked result |
| --- | --- | --- | --- |
| Page/section/element | Actual text for this location | Source for material claims, relevant qualifications and confirmed destination | Exact missing fact or observed check |

Keep support and gaps out of public text. Put a qualification in the wording itself when omitting it would mislead. When alternatives are useful, label the changed angle and retain the same verified offer. Do not mix draft variants into a single page unintentionally.

For a hook, include the continuation that resolves its promise or identify the existing section that does. A product demonstration can establish an observable capability; it cannot supply an unmeasured customer outcome.

## Conditional checks and sources

For campaign arrivals, compare the source promise with the page and destination. [Google Ads guidance](https://support.google.com/google-ads/answer/6238826?hl=en) supports matching those expectations and making useful information easy to find; it does not establish a conversion guarantee.

For unclear or ornate wording, use [GOV.UK's clear-language guidance](https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/writing-guidelines/clear-language/) as a reference for audience vocabulary and explained specialist terms. Its house-style rules are not universal copy requirements. For calls to action, [W3C's link-purpose guidance](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html) supports understandable destinations and consistent identification. Copy inspection alone cannot establish accessibility conformance.

When search metadata is requested, provide a descriptive page-specific title and accurate summary. Use [Google's title-link guidance](https://developers.google.com/search/docs/appearance/title-link) and [snippet guidance](https://developers.google.com/search/docs/appearance/snippet): display may truncate to fit the device, and Google may generate a different title or snippet. Avoid fixed character quotas or promised search appearance. Keep keywords natural and metadata consistent with the visible page.

These primary pages were checked on 2026-10-06. Recheck current guidance when its behavior matters to the task; none proves that a particular draft will improve conversions.

## Evidence to retain

Record which copy and sources were checked, the before/after text when useful, inspected revision and surfaces, destination observations, missing facts and the independent assessment. Separate draft checks from rendered inspection, participant observations and measured outcomes. Refresh affected evidence after edits.
