# Media

This domain owns produced media and its production evidence. Its first package creates code-driven motion graphics and explainers. Content owns reusable voice and editorial prose; UI/UX owns interactive interfaces and their motion.

## Categories and skills

| Category | Subcategory | Skill | Expected result |
| --- | --- | --- | --- |
| Video production | Motion graphics and explainers | [create-motion-video](../../skills/media/create-motion-video/SKILL.md) | A clarified brief, timed script/storyboard and requested editable/rendered result with scoped visual, technical and applicable audio proof |

## Boundaries

Start from accepted inputs and finish at the requested fidelity. A storyboard-only request does not need a full export. An existing composition can receive a scoped repair without restarting discovery. The package supplies a workflow and templates, not a bundled renderer, style gallery or narration service. Required tools and assets belong to the consuming environment.

Use `design-interface` for interactive UI transitions; `define-writing-voice` for reusable language conventions; `review-writing` for a prose-only assessment. `create-motion-video` owns its spoken script and timing. Upload, publication and provider spending need applicable authority. Missing tools or playback/audio access leave explicit gaps; contact sheets and source review alone do not establish a completed video.
